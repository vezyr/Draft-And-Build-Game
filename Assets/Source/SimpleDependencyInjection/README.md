Simple Dependency Injection written for:
- just for fun :)
- to demonstrate knowledge of how DI can work internally (it's not a 'magic box')
- for production purpose, some more mature DI framework should be used (written internally or third party one like Zenject)

For proper working, make sure that:
- set `GameObject` with `SceneContext` component on your scene;
- set `SceneContext` as one of the first scripts in the Script Execution Order;
